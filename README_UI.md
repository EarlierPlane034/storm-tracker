## 📡 Tab Breakdown

### 1. **Radar** (Default)
**What you see:**
- Live NEXRAD reflectivity (color-coded intensity)
- Storm cells with severity scores
- Radar product selector (left side)
- Animation controls (bottom)
- Map layers: Outlook, observations

**How to use:**
- Tap any colored circle = View that storm
- Select product from left rail = Change radar type
- Play/pause = Animate radar loop
- Drag slider = Jump to specific time

---

### 2. **Storms**
**What you see:**
- List of all detected cells
- Severity score (0-100) for each
- Storm type (Supercell, QLCS, etc.)
- Distance from you
- ETA if moving toward you

**How to use:**
- Tap any storm = Opens detailed sheet
- Sort by Score or Distance
- Shows how many storms hidden by filters

---

### 3. **Alerts**
**What you see:**
- Active NWS tornado warnings 🌪️
- Severe thunderstorm warnings ⚡
- Flash flood watches 🌊
- Winter storm warnings ❄️
- Storm-specific polygons on map

**How to use:**
- Review all active alerts
- Tap to see details
- Red = Most critical
- Filter by distance in Settings

---

### 4. **Reports**
**What you see:**
- Storm reports from chasers and spotters
- Verified sightings (✅ marks)
- Pending verification (⏳ marks)
- Photos and descriptions
- Time and location of each report

**How to use:**
- Read real observer reports
- Submit your own via form
- Help verify reports from others

---

### 5. **Analysis** ⭐ NEW!
**What you see:**
- 6 sub-tabs for deep analysis:

| Tab | Content |
|-----|---------|
| **Overview** | Quick summary of selected storm |
| **Hodograph** | Wind shear profile, SRH values |
| **Environment** | CAPE, LCL, freezing level heatmaps |
| **Trends** | Storm lifecycle, metric graphs |
| **Rankings** | Compare 2-3 storms side-by-side |
| **Performance** | Render stats, mobile optimization |

**How to use:**
1. **Select a storm** on map
2. **Open Analysis tab**
3. **Browse sub-tabs** for detailed info

**Key Metrics:**
- 🌪️ CAPE > 2000 = Unstable
- 📐 Shear > 25 kt/km = Rotation support
- 🎯 LCL < 1000m = Easier tornadoes
- 📈 Trends show intensification rate

---

### 6. **Week 3** ⭐ ALL NEW!
**What you see:**
- 8 sub-tabs for advanced analysis:

| Tab | What it does |
|-----|--------------|
| **🤖 ML Predictions** | AI hail/tornado probability |
| **👥 Community** | Spotter reports & leaderboard |
| **🔮 Forecasting** | Hail swath, tornado zones |
| **🎙️ Voice** | Voice alerts & narration |
| **🛡️ Chase Safety** | Routes, shelters, go/no-go score |
| **💾 History** | Database, statistics, export |
| **📈 Charts** | 3D storm visualization |
| **🎓 Training** | Lessons, quizzes, certification |

**How to use:**
1. **Select a storm** on map first
2. **Open Week 3 tab**
3. **Browse each sub-tab** for insights

**Most Important: Chase Safety Tab**
- Shows safest intercept route
- Lists nearest safe shelters
- **Go/No-Go Score (0-100)**:
  - 🟢 75+: GO - Excellent opportunity
  - 🟡 60-74: GOOD - Chase if ready
  - 🟠 40-59: MARGINAL - Not recommended
  - 🔴 <40: NO-GO - Too risky

## 🚀 Typical Storm Chasing Workflow

### Step 1: Monitor
```
Open Radar tab → Watch for developing storms → Look for rotation
```

### Step 2: Analyze
```
Tap suspicious cell → Open Analysis tab → Check Hodograph & Environment
```

### Step 3: Assess
```
Open Week 3 tab → Check ML Predictions → Review Chase Safety
```

### Step 4: Decide
```
Look at Go/No-Go Score → Check safe havens → Plan intercept route
```

### Step 5: Chase
```
Follow planned route → Monitor lightning alerts → Watch Alerts tab
```

### Step 6: Document
```
Submit storm report → Take photos → End chase session
```

### Step 7: Learn
```
Open Analysis tab → Review Trends → Check accuracy metrics
```

## 📱 Mobile Tips

### Screen Size Optimization
- **Portrait mode** (recommended) - All tabs visible
- **Landscape mode** - Swipe left to see more tabs
- **Small phones** - Tap tab text, not icons

### Touch Gestures
- **Tap storm circle** → View details
- **Tap feature card** → Navigate directly
- **Swipe left on tabs** → Scroll to more options
- **Pinch on map** → Zoom in/out
- **Long press** → More options (some cards)

### Battery Saving
- Settings → Data Saver ON
- Settings → Chase Mode OFF (when not chasing)
- Reduce screen brightness
- Close other apps

## 🆘 Troubleshooting

### Radar won't update?
- Check Settings → Refresh rate
- Verify internet connection
- Try different radar product

### Alerts not showing?
- Settings → Alerts → Enable notifications
- Check alert distance radius
- Verify your location is enabled

### App is slow?
- Settings → Data Saver ON
- Close other apps
- Reduce animation FPS in Settings

### Can't find a feature?
- Tap "?" button → Quick Start Guide
- Open "Features" tab → Visual dashboard
- Check FEATURES_GUIDE.md for detailed docs
